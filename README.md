## Fortune Cookie for the Liquidated Trader

One fortune-cookie line for a crypto trader who has just been liquidated,
written to be read at 3am with an empty wallet and a stubborn sense of
humour. The program writes a single line of plain text to
`/output/entry.txt`:

> Your lucky numbers are 0, 0, 0 — the same as your balance after that last trade.

The joke keeps the classic fortune voice — lucky numbers, oracular
phrasing — and lets the punchline break it: the numbers are the trader's
own balance. Rueful, warm, and over in a single breath (17 words).

## Run

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt`. For local checks, set
`ENTRY_OUTPUT` to another path. The program asserts the fortune passes
the gate (1–160 characters, at most 20 words, one line) before writing.
